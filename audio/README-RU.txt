ГОЛОС ДЖОННИ — ИНСТРУКЦИЯ
==========================

Настоящий голос Джонни Сильверхенда — это аудио из игры Cyberpunk 2077.
Автоматически скачать его нельзя (защищено авторским правом), но если у
тебя есть лицензионная копия игры, ты можешь извлечь фразы сам и положить
их сюда — сайт подхватит их и будет играть вместо синтезированного голоса.

ВАЖНО: используй только файлы из собственной лицензионной копии игры.

КАКИЕ ФАЙЛЫ КЛАСТЬ
------------------
Файлы должны быть .mp3 (или .ogg).

1) johnny_wakeup.mp3 — культовая фраза:
     «Проснись, самурай. У нас дела.»
   Она играет при входе в архив и в галлюцинациях.
   Если файла нет — сайт скажет эту фразу синтезированным голосом.

2) johnny_1.mp3 … johnny_12.mp3 — любые фразы Джонни ротацией
   (случайная реплика при каждом обращении к Джонни).
   Можно положить хоть 1 файл, хоть 12 — сколько есть.

КАК ИЗВЛЕЧЬ ФРАЗЫ ИЗ ИГРЫ
--------------------------
- Оригиналы реплик лежат в файлах из архива игры (искать по тексту фраз).
- Либо перепиши голос Джонни программно с твоей установки игры (audioware,
  redmod / wolvenkit) — только с собственной копии.
- Либо запиши свои цитаты — главное, чтобы хотелось их слышать.

ПОСЛЕ КЛАДКИ ФАЙЛОВ
-------------------
- Перезапусти dev-сервер (или собери сайт: npm.cmd run build).
- Убедись, что в браузере включён звук (галочка в хедере сайта).

ТЕХНИЧЕСКАЯ СХЕМА
-----------------
При загрузке сайт делает HEAD-запрос к /audio/johnny_1.mp3 … johnny_12.mp3
и /audio/johnny_wakeup.mp3. Найденные файлы начинают использоваться
автоматически в качестве голоса Джонни; если ни одного файла нет — работает
синтезированный голос (плюс низкий growl-фон).
